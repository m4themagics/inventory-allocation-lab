# Reports

Результатов пока нет.

Один отчёт — на один эксперимент из `experiments/`. Отчёт появляется только после того, как
пройден publication gate из [research protocol](../docs/research-protocol.md): тесты
корректности зелёные, протокол не менялся молча после просмотра числа, посчитана
неопределённость, разобраны ручные примеры.

Рабочая таблица, полученная прогоном, — это ещё не результат. Результат — это paired cost
difference с интервалом, у которого записаны команда, seed, commit, fingerprint входных
данных, solver version и доля fallback.

Каждый отчёт содержит раздел «что не сработало». Timeout, infeasibility и policy, проигравшая
эвристике, не удаляются из истории и не переименовываются в “edge case”.
