# Tests as learning artifacts

`test_scaffold.py` проверяет только здоровье документационного scaffold и явность
незаполненных experiment decisions. Всё остальное пишет автор перед кодом, который оно
тестирует.

Для каждого core TODO:

1. решить маленький пример руками;
2. добавить падающий тест;
3. запустить и записать failure;
4. реализовать минимум, который проходит;
5. добавить boundary и failure-mode tests;
6. объяснить, какую правдоподобную неверную реализацию этот тест ловит.

Для MILP обязательна дополнительная сверка с полным перебором. Тест, который только проверяет
`solver_status == optimal`, не доказывает правильность formulation.

Не просить агента сгенерировать полный test suite до собственной попытки. См.
[LEARNING.md](../LEARNING.md).
